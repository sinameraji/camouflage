› explain the compact region

  The compact region replaces the tool rows and the plan while a turn is running. Each tool
  contributes one bead, so a long run of reads stays a single line. When the turn settles the
  region is cleared and the finished blocks print once. That keeps the live frame a fixed height no
  matter how long the turn gets.
